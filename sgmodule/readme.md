# Surge Modules (sgmodule)

本文件夹存放 Surge 的 `.sgmodule` 模块文件，均为个人自用配置。

## 模块列表

| 模块名称 | 功能描述 |
|----------|----------|
| **BiliBili解锁高画质.sgmodule** | Bilibili（哔哩哔哩）高清画质解锁 |
| **Coolapk_Redirect.sgmodule** | 酷安应用链接重定向 |
| **NetBlockCheck.sgmodule** | 网络阻断检测 |
| **PingMe签到.sgmodule** | PingMe 签到 |
| **SkyQueueBypass.sgmodule** | Sky光·遇插队进入 |
| **iKuuu签到.sgmodule** | iKuuu 签到 |
| **广汽本田屏蔽更新.sgmodule** | 广汽本田 App 更新屏蔽 |

## 使用方法

1. 在 Surge 中打开 **模块** 界面
2. 选择 **从 URL 下载**
3. 输入对应模块的 raw URL（推荐）

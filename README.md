# Surge

surge 相关自用配置、脚本与模块

个人收集和维护的 Surge（iOS/macOS 网络代理工具）配置文件仓库，包含常用规则、JavaScript 脚本和 Surge 模块。

## 仓库目录

- **`/js`**：JavaScript 脚本
- **`/rules`**：规则列表（.list 文件）
- **`/sgmodule`**：Surge 模块（.sgmodule 文件）

## 功能亮点

### 脚本（/js）
- **B站画质解锁**：解除 Bilibili 高清画质限制
- **Coolapk Redirect**：酷安应用重定向
- **签到脚本**：iKuuu 签到、PingMe 签到
- **网络检测**：block_check_surge、Sky Queue Bypass
- **其他**：TestFlight 相关、GitHub 版本检查等

### 规则（/rules）
- Apple Intelligence 规则
- Apple 证书验证屏蔽
- 王者荣耀国际服 规则
- 更多自定义规则

### 模块（/sgmodule）
- BiliBili 高画质解锁模块
- 各类签到模块
- 网络阻断检查模块
- 应用更新屏蔽（如广汽本田）
- SkyQueueBypass 等

## 注意事项

- 本仓库为个人自用配置，仅供参考
- 请根据自身网络环境和需求调整规则
- Surge 版本建议使用较新版本以获得最佳兼容性
